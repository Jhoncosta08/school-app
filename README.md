# School App

## About the project
>This is a student management system where you can register and view information about students, subjects, and exams. The application allows for CRUD (Create, Read, Update, Delete) operations on:

>* Students: Add new students, view registered ones, and display their grades for each associated subject.
>* Subjects: Create new subjects and display the list of available subjects for assigning grades to students.
>* Exams: Assign grades to students for each registered subject, with the ability to edit or delete these records.

## Main technologies used in the project
>* This project was generated with [Vue.js](https://vuejs.org/).  A JavaScript framework for building dynamic and reactive user interfaces.
>* This project has implemented [Vuetify](https://vuetifyjs.com/en/) A UI component library for Vue.js, providing a modern and responsive look and feel.
>* This project has implemented [Vue Router](https://router.vuejs.org/) For route management and navigation within the application.

## How to clone and setup up the project
> - [x] Clone the project, use de code: `git clone <project-url>` to clone the project.
> - [x] Open the CMD or IDE of your preference, navigate to the cloned project.
> - [x] Inside the project folder, install npm packages, use de code: `npm i` to install the packages.
> - [x] Run the project, use de code: `npm run serve` to run the project.

## Development server
> Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.
